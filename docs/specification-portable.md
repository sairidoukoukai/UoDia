## 1. 本書の位置づけ

**インストーラーを通さずに配れる形を決める。** 展開して実行し、要らなくなったらフォルダごと消せるものを作る。

仕様書 v1.0 §10.4 は「**どこにでも置ける成果物を作る**」としている。本書はその延長であり、**置き場所だけでなく実行のされ方も選べるようにする。**

### 1.1 なぜ要るか

| | |
| --- | --- |
| **入れる権限が無い環境がある** | 大学の共用端末に管理者権限は無い |
| **持ち歩きたい** | USB メモリに入れて別の端末で続きを描く |
| **試すのに入れたくない** | 一度使ってみるためにインストーラーを走らせたくない |

### 1.2 本書が扱わないこと

- **自動更新。** ポータブル版に更新の仕組みは入れない（[§7](#7-更新)）
- **Web 版。** 既にインストール不要であり、本書の対象ではない
- **インストーラー版を廃止すること。** 両方を配る

## 2. ポータブル版とは何か

> **決め: 自分の置かれたディレクトリの外に、何も書かない。**

これが唯一の定義である。**「インストーラーを使わない」は結果であって、定義ではない。** 展開しただけで動いても、設定を `%APPDATA%` に書くなら持ち歩けていない——別の端末に挿したときに、置いてきたはずの設定が付いてこない。

### 2.1 いま外に出ているもの

デスクトップ版は 4 つのファイルを設定ディレクトリに置く（`src-tauri/src/paths.rs`）。

| ファイル | 中身 | 失うと |
| --- | --- | --- |
| `settings.json` | 見た目・自動保存の間隔 | 既定に戻る。**作り直せる** |
| `backup.uodia` | 自動バックアップ | 復元できない。**作り直せる** |
| `recent.json` | 最近使ったファイル | 履歴が消える。**作り直せる** |
| `route.json` | **運行経路の定義** | **文書の意味が変わる**（時刻が別物になる） |

**4 つめだけが質的に違う。** ほかの 3 つは無くても文書は同じものとして開くが、`route.json` が違うと**同じ `.uodia` が別の時刻表になる**——便が保存しているのは基準時刻 1 点だけで、残りは `segments.runMinutes` から導出されるためである。

**[#235](https://github.com/sairidoukoukai/UoDia/issues/235) で `route.json` は `.uodia` に取り込まれる。** そのあと外に残るのは**捨ててよいものだけ**になる。

> **本書は #235 を前提にしない。** #235 が入っていなくてもポータブル版は成り立つ——`route.json` も置き場所を移せばよい。ただし**#235 が入るまでは、持ち歩いた先で路線が食い違う余地が残る**（[§8](#8-未確定事項) の P-2）。

## 3. どこに書くか

> **決め: 実行ファイルと同じディレクトリの `data/` に置く。**

```
UoDia/
├── UoDia.exe          ← 実行ファイル
├── resources/         ← 同梱リソース（route.json・OFL.txt）
└── data/              ← ここに書く
    ├── settings.json
    ├── backup.uodia
    ├── recent.json
    └── route.json     （#235 が入るまで）
```

**`data/` を掘るのは、実行ファイルの隣を散らかさないためである。** フォルダを開いた人が「どれがアプリで、どれが自分のものか」を見分けられる。

### 3.1 macOS だけ隣が違う

`.app` は**ディレクトリだが、中身を書き換えると署名が壊れる。** バンドルの中には書かない。

```
UoDia.app
data/                  ← .app の中ではなく、隣
```

**`.app` と同じ階層に置く。** ドラッグ&ドロップで移動したときに `data/` が付いてこないが、**署名を壊すよりはよい**——付いてこないことは目で分かるが、壊れた署名は起動しなくなるまで分からない。

## 4. ポータブルかどうかをどう決めるか

> **決め: 実行ファイルの隣に `portable` という名前のファイルがあれば、ポータブル版として振る舞う。**

中身は見ない。**あるかどうかだけを見る。**

### 4.1 なぜビルドで分けないのか

選べる形は 3 つある。

| | |
| --- | --- |
| **目印のファイル** | 1 つのバイナリで済む。**置かれ方**で決まる |
| ビルドの分岐（フィーチャフラグ） | 配布物が別物になり、CI の作る成果物が 3 OS × 2 に増える |
| 環境変数 | 起動のたびに要る。ダブルクリックで起動できない |

**目印のファイルを採る。**

**ポータブルかどうかは、そのバイナリの性質ではなく、置かれ方の性質である。** ビルドで決めると、インストーラー版のバイナリを USB に置いてもポータブルにならず、**同じものが 2 つ並ぶ**。目印で決めれば、配るバイナリは 1 つで済む。

**CI が作る成果物を増やさない。** いまでも 3 OS で 7 点あり、これを倍にすると「どれを配ったか」を追えなくなる。

### 4.2 書けなかったときどうするか

> **決め: 設定ディレクトリへ倒さない。エラーを出して、書けなかったことを伝える。**

目印を置いた人は**そこに書かせたいのである。** 黙って `%APPDATA%` へ倒すと、**持ち歩いたつもりのものが端末に残る**——ポータブル版として最も避けたい壊れ方である。

**読み取り専用の媒体に置かれることはある**（CD-ROM、書き込み保護した USB）。そのときは起動して**編集はできるが保存できない**状態になる。これは Web 版の `networkDefWritable: false` と同じ形であり、**できないことを先に伝える**（仕様書 §6.5.5 と同じ扱い）。

## 5. 何を配るか

> **決め: 圧縮した書庫を 1 つ。展開すればそのまま動く。**

| OS | 形 | 中身 |
| --- | --- | --- |
| Windows | `UoDia-<版数>-windows-x64-portable.zip` | `UoDia.exe`・`resources/`・`portable`・`README.txt` |
| Linux | `UoDia-<版数>-linux-x64-portable.tar.gz` | `uodia`・`resources/`・`portable`・`README.txt` |
| macOS | `UoDia-<版数>-macos-aarch64-portable.zip` | `UoDia.app`・`portable`・`README.txt` |

**`portable` を最初から入れておく。** 展開しただけでポータブルとして動く。**入れないと、利用者が自分で作ることになる**——それを説明する文章を書くくらいなら、入れておくほうが短い。

### 5.1 `README.txt` に書くこと

**3 つだけ書く。**

1. **展開したフォルダごと持ち歩ける**こと
2. **`data/` に自分のものが入る**こと（消せば初期状態に戻る）
3. **`portable` を消すと、普通のインストール版と同じ場所に書く**ようになること

### 5.2 Windows の WebView2

> **決め: 同梱しない。システムのものを使う。**

Tauri は WebView2 を使う。Windows 10 の 2021 年以降の更新と Windows 11 には**既定で入っている。**

**固定版を同梱すると 150MB 前後になる。** ポータブル版の利点（持ち歩ける・すぐ試せる）を、**それを配るための重さで打ち消す。**

**入っていない環境では起動しない。** `README.txt` に必要なものとして書く——**動かない理由が分かる形で残す**ほうが、150MB を全員に配るよりよい。

### 5.3 Linux の AppImage との関係

**AppImage は既にインストール不要だが、ポータブルではない。** 設定を `~/.config` に書くためである。

**AppImage は今までどおり配る。** ポータブル版は別の成果物とする——同じものに 2 つの意味を持たせない。

## 6. 検証

**「何も残さない」は、残らなかったことを確かめないと言えない。**

| 何を | どう |
| --- | --- |
| 外に書かないこと | 起動→編集→保存→終了のあと、**設定ディレクトリに新しいファイルが無い**ことを確かめる |
| `data/` に書くこと | 同じ操作のあと、`data/` に 3 つ（#235 前は 4 つ）できることを確かめる |
| 目印が無ければ従来どおり | `portable` を消して起動し、**設定ディレクトリに書く**ことを確かめる |
| 書けない媒体 | 読み取り専用にして起動し、**エラーが出て、設定ディレクトリに落ちない**ことを確かめる |

**設定ディレクトリの中身を、起動の前後で数える。** これは手で数えられる規模であり（4 ファイル）、CI に載せるかどうかは実装時に決める（[§8](#8-未確定事項) の P-1）。

## 7. 更新

> **決め: 自動更新は入れない。**

インストーラー版にも入っていない。**ポータブル版だけ先に持つ理由が無い。**

新しい版は**書庫を落として展開し、`data/` を移す。** `README.txt` に書く。
